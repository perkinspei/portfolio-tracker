手动导出

默认情况下所有数据只保存在这台设备的浏览器里，不会上传到任何服务器。
只有当你主动开启上面的「多设备同步」时，数据才会发送到你自己 GitHub 账号下的 Gist。
换设备、清理浏览器缓存前，也建议「导出备份」保存一份 JSON 文件。
